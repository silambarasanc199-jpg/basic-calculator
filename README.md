# 🧮 Basic Calculator

A modern, responsive basic calculator built using HTML, CSS, and JavaScript.

## 🚀 Live Demo

https://silambarasanc199-jpg.github.io/basic-calculator/

## ✨ Features

- Addition
- Subtraction
- Multiplication
- Division
- Decimal number support
- Clear (AC) function
- Delete (DEL) function
- Equals calculation
- Divide-by-zero handling
- Keyboard support
- Input handling and validation
- Responsive mobile-friendly design
- Modern futuristic user interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
